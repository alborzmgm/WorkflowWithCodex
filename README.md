# WorkflowWithCodex

A minimal form demo app showcasing:

- Improved checkbox list UI (card-like options, better spacing, selected chips)
- Extended `visibleWhen` logic with operators:
  - `contains`
  - `hasValue`
  - `isEmpty`
  - `notEquals`

## Run

```bash
npm test
npm start
```

Then open http://localhost:4173.
